# R36S pixel-art packs

Generated by `tools/build_pixel.py`. File names match the EmulationStation theme folder names
(`snes.png`, `megadrive.png`, `pico-8.png`, …) used by ArkOS / dArkOS and by the NeonGlow theme.

* `logos/`: 194 pixel-art system logos (transparent PNG, 4× nearest-neighbour upscale of a ≤176×64 pixel grid, ≤24 colours)
* `consoles/`: 149 pixel-art consoles, handhelds, computers and arcade boards (transparent PNG, 4× upscale of a ≤160×112 grid, ≤32 colours)

## Collection logos (original pixel art)

`auto-favorites` / `favorites` (gold star), `auto-allgames` / `all` (game cartridge) and `auto-lastplayed` / `recent`
(clock) are original pixel art drawn by `tools/build_pixel_collections.py`. They use a chunky pixel font, banded
gradients, a 1-pixel outline and a drop shadow, in the style of 8/16-bit title screens.

## How the system logos and consoles are made (no redrawing)

Each image is the original artwork sampled onto a coarse pixel grid (area average), reduced to a small palette
without dithering, given a hard-edged alpha, and scaled up with nearest-neighbour. Nothing is redrawn,
recoloured or restyled: shapes, proportions, markings and colours come straight from the source artwork.

## Not included

* **Consoles:** only real hardware gets one. Not included: collections (favorites, recent, all…), menus
  (options, tools, retropie, setup, retroarch), ports and game engines (scummvm, openbor, doom, wolf, easyrpg, solarus,
  love2d, lutro, onscripter, cavestory, puzzlescript, j2me, vhs, mess) and fantasy consoles (pico-8, tic80, wasm4,
  lowresnx, vircon32).
  These systems are real hardware, but the source packs have no image of the device and none could be fetched,
  so they were left out rather than drawn from memory: `gametank`, `microvision`, `palm`, `piece`, `tvc`, `vmu`,
  `acclaim`, `alg`.
* **Logos:** `gametank`, `microvision`, `onscripter`, `piece`, `puzzlescript`, `retroarch`, `tvc`, `vhs` and `vmu`
  have no official logo in the source packs, so they get a plain pixel wordmark of the name instead.
