# Fonts

Self-hosted variable fonts (Latin subset), loaded in `src/theme/fonts.ts`.

| File | Family | License |
| --- | --- | --- |
| `Inter-Variable.woff2` | Inter (400–700) | SIL Open Font License 1.1 |
| `SpaceGrotesk-Variable.woff2` | Space Grotesk (400–700) | SIL Open Font License 1.1 |

Both are distributed via Google Fonts. Add new fonts here and register them
with `loadFont()` from `@remotion/fonts`.
