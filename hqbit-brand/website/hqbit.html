Install

On your R36S in three steps

You only need a computer that can read the SD card. Nothing outside the theme folder is changed, so removing a theme is just deleting its folder.

Works with

The R36S and its 640×480 clones running EmuELEC, ArkOS or dArkOS, and firmware variants based on these systems.

  • EmuELEC
  • ArkOS
  • dArkOS
  • Variants built on these

  1. Download and unzip

    Download the theme's zip and unzip it on your computer. If you get a folder inside a folder with the same name, use the inner one.

  2. Copy it to the SD card

    Put the SD card in your computer and copy the theme folder into EASYROMS/themes/ on ArkOS and dArkOS. On EmuELEC, copy it to EmulationStation's themes folder, /storage/.config/emulationstation/themes/, over the network share or SSH.

  3. Switch to it

    Press Start → UI Settings → Theme Set and pick the theme. Colours, layouts and font sizes are under Theme Configuration. Restart EmulationStation if it doesn't switch right away.

If it gets stuck

Boot loop after applying a theme?

If your R36S keeps restarting after you switch to one of the themes:

  1. Turn the device off and take out the SD card.
  2. Put the SD card into your computer and delete the theme folder you just selected from the themes folder.
  3. Put the SD card back into your R36S and turn it on. It will start with your default system theme.
About HQbit

A first project, and a starting point

HQbit is the pixel art and UI project of Hossam el Qamash. It started with one R36S clone and a simple question: can a first-time theme maker, working with AI, build EmulationStation themes that look good on a 640×480 screen?

These four themes are the answer so far. They were designed together with Claude, an AI assistant, and generated by code, so every logo, icon and layout is drawn at the screen's real pixel size. Volta runs on my own R36S clone, and the themes were checked in a desktop build of ArkOS's EmulationStation that uses the same graphics mode as the handheld. They're made for the EmulationStation builds in EmuELEC, ArkOS and dArkOS.

This is my first project of this kind, so there is plenty of room to improve. I'd rather share it now and keep making it better than wait for perfect. It's also the start of more projects like it, for the R36S and for other popular handhelds.
